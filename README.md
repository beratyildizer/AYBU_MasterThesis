This repo includes benchmark codes, scripts and bechnmark experiment results for my master thesis.

My thesis title is "PERFORMANCE ANALYSİS OF IPC MECHANISMS ON REAL TIME LİNUX KERNEL (PREEMPT-RT) FOR ARM-BASED EMBEDDED DEVICES"

Abstract
This thesis evaluates the real time performance of pipe, POSIX message queues 
and shared memory with semaphores inter-process communication mechanisms 
under different Linux preemption models on ARM-based embedded systems as 
well as investigating real time capabilities of Linux with a particular focus on the 
PREEMPT_RT configuration. The evaluation focuses on latency, jitter, and 
worst-case response times to assess the impact of kernel preemptibility. Morever, 
this thesis aims to provied a guide for developers who wish to implement real
time software on Linux using different inter-process communication mechanisms.
 
Keywords: PREEMPT_RT, Real Time Linux, Inter Process Communication, 
Embedded Systems, ARM
